# ── Machine translated language paths ──
# The site is readable in ~103 languages. Body copy outside the ten hand
# written locale files is translated in the visitor's browser at runtime, so
# those URLs have NO translated HTML for a crawler to read: fetching /ja/about
# returns the English page plus a script. Every one of them is noindex.
#
# WHY DISALLOW AND NOT JUST noindex. A noindex is only obeyed after the page
# has been fetched, so on its own it still costs a crawl for every URL. With
# ~103 languages across 31 pages that is roughly 3,200 fetches of machine
# translated duplicates, which would consume this site's whole crawl allowance
# and return nothing indexable. This site had to dig its location pages out of
# "discovered, currently not indexed" once already; spending the budget this
# way is how that happens again.
#
# These are NOT hidden from users, and nothing here is cloaking: the pages are
# reachable, linked from the header menu, and identical for humans and bots.
# This only tells crawlers not to spend their allowance on translations that
# cannot be indexed anyway.
#
# WHEN A LANGUAGE IS GENUINELY REVIEWED, REMOVE ITS LINE HERE. A published,
# reviewed translation is a real page and must be crawlable, or its hreflang
# and sitemap entries will be ignored. Deleting the matching Disallow is the
# other half of promoting a locale, alongside setting provenance to 'reviewed'
# and published to true in its locale file.
#
# English has no prefix, so nothing below affects it.
Disallow: /ar/
Disallow: /de/
Disallow: /es/
Disallow: /fr/
Disallow: /hi/
Disallow: /kn/
Disallow: /ml/
Disallow: /ta/
Disallow: /te/
